# CampusFlow-UG-Prototype 🚀

Plataforma académica inspirada en la Universidad de Guayaquil, desarrollada en Django. Sistema con 3 roles: Secretaría, Docente y Estudiante.

### 🔗 Demo en vivo
**https://plataformainstitucional-gyrw.onrender.com**

> ⚠️ Prototipo educativo no oficial. No afiliado a la UG. Hecho con fines académicos.

### ✨ Funciones
- **Secretaría:** CRUD usuarios, carga masiva por Excel, matrículas
- **Docente:** Aulas, calificación de tareas
- **Estudiante:** Dashboard, entrega de tareas, horarios

### 🛠 Stack
Python, Django, TailwindCSS, SQLite, Render
